# Open ADMS — Decisions (ADR-599 on)

> **ADR-001…598 are in `agent_store/history/DECISIONS-001-598.md`** (2.4 MB, never read whole: grep
> it, `grep -n '^| \*\*ADR-517' agent_store/history/DECISIONS-001-598.md`). Numbers carry on from
> there and are never reused or renumbered. **Append, never rewrite.**
>
> **When an ADR is written** (ADR-599): a decision about the product, money, evidence, what a
> monitor must do, security, a new dependency, or the architecture; the user's answer to a
> question; an agent default the user may overturn (marked **agent default**). Ordinary
> engineering inside an approved design is said in the code and the commit message, not here.
>
> **A row is short:** the decision, why, and the rule it leaves, in a few sentences. Never a build
> log, a file list, a test list or a count (those are the code, the commit and `CHAIN.md`).
>
> **What's true now:** the newest row here wins; then `agent_store/SUMMARY.md` (frozen at ADR-598,
> read by topic); then the skills; then the spec drafts. A row that changes a skill's rule updates
> that skill in the same work, marked with its ADR.
