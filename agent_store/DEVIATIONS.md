> what blocks Phase 1 exit. This file is the full log.

**Read this at orientation** so you do not "rediscover" a gap already logged.
**Append, never rewrite. Never renumber.** Entries marked 🟡 / 🔴 are blocked on the user —

> platform is being rebuilt from the plan (ADR-093, ADR-103). The KDs against `database/` code
